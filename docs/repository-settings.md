# Repository settings

These are set in the GitHub UI, not in code. Copy and paste.

## Description

**Settings → Description**, or the gear next to **About** on the repo home page.

```
Download an entire Google Drive folder at once, straight to disk with the folder structure intact. No 2GB zip splits to reassemble, no sign-in, no uploads. A single static HTML page that streams files from Drive into a folder you pick. Free and open source.
```

Within GitHub's 350 character limit.
