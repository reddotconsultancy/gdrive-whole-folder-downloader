# Suggested repository settings

Copy and paste these into GitHub. Neither is set by code.

## Description

Settings → paste into the **Description** field at the top of the repo page.

> Download an entire Google Drive folder at once, straight to disk with the folder
> structure intact. No 2GB zip splits to reassemble, no sign-in, no upload. A single
> static HTML page that runs in your browser and streams files from Google Drive to a
> folder you choose. Free and open source.

(288 characters, within GitHub's 350 limit.)
