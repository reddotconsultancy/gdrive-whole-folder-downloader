Download a whole Google Drive folder at once

The key stays in this browser. We never receive it, store it, or send it anywhere but Google. There is no server here to send it to.

How to get a key
  1. Create a project — type any name, click Create, wait a few seconds.
  2. Enable the Google Drive API — make sure your new project is selected at the top, click Enable.
  3. Create credentials — Create credentials, API key, then copy the key it shows you.
  4. Paste it in the box above. It is free and Google does not ask for a card.
  • Runs entirely in your browser. Files go straight from Google to your disk.
  • Nothing is stored. No sign-in, no account, no link history, no analytics.
  • The whole folder in one go, structure intact — no 2GB zips to piece together.
  • Downloads several files at once, so it finishes faster.
  • Stops halfway? Run it again and it picks up where it left off.

Works on folders shared "anyone with the link". Chrome, Edge and Opera rebuild the folders on disk; other browsers save the files one by one. Google Docs, Sheets and Slides are converted to Office files.
